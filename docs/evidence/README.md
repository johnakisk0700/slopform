# Evidence

Findings about systems and scope, recorded at a date. Evidence states what was
observed; it does not decide anything and does not describe this repository's
current code.

Each file is fixed to its date. If reality has moved, take new evidence rather
than editing the old — an amended observation is no longer an observation.
